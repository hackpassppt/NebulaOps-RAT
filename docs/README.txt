NebulaOps Forum Release
=======================

What this is
------------
Official NebulaOps Control Center package (main program + runtime dependencies).

Requirements
------------
- Windows (x64 recommended)
- .NET Framework 4.5.2 or newer

How to run
----------
1. Extract ALL files into the same folder (do not copy only the EXE)
2. Launch NebulaOps.exe
3. If Certificate Wizard appears, follow the prompts
4. Enter the Control Center and use War Room / Mission / Graph / Beacon / etc.

Included
--------
- NebulaOps.exe and required DLLs
- README.txt
- NebulaOps_Feature_Guide.docx
- NebulaOps_Feature_Guide.md

Not included
------------
- Source code
- Upload tooling
- Dev / test junk files

Notice
------
Use only in authorized labs, training environments, or systems you own.
